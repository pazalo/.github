# pazalo/.github

The organization profile for [Pazalo](https://github.com/pazalo).

The `README.md` at the root of this repository is what GitHub renders on
https://github.com/pazalo — the organization's front page.

`assets/` holds the brand mark in the sizes a README needs. Every file in it is
committed so it can be served from `raw.githubusercontent.com`, which is the only
host that survives GitHub's sanitised README sandbox.
